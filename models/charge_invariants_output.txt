== 5. A side fixed by a rule n = f(v) alone ==

Analytic argument for all rotations (SO(3)) and reflection: on states with n ∥ c write n = s·c, s = ±1.
SO(3) acts transitively on pairs (v, c) of orthogonal unit vectors, so an invariant can depend only on s;
P leaves the axial vectors n, c unchanged, so s is P-even; C sends s → −s. Hence s = n·c is the only charge-like sign there.
